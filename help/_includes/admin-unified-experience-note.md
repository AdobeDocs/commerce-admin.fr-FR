# Remarque sur l’expérience unifiée de l’administrateur

>[!NOTE]
>
>L’administrateur Commerce dans Adobe Commerce as a Cloud Service utilise l’expérience unifiée Adobe, avec une navigation supérieure Adobe partagée et une navigation de gauche Commerce mise à jour. Voir [Commerce Admin dans l’expérience unifiée Adobe](/help/getting-started/admin-unified-experience.md) pour plus d’informations. Les captures d’écran de cette page présentent l’interface d’administration Commerce classique utilisée par Adobe Commerce sur les déploiements sur site et les infrastructures cloud.
