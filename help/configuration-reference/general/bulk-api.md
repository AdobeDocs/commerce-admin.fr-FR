| Champ | [Portée](../../getting-started/websites-stores-views.md#scope-settings) | Description |
|--- |--- |--- |
| [!UICONTROL Maximum Entities Per Bulk Request] | Global | Affiche le nombre maximal d’entités pouvant être traitées dans une seule demande en bloc. Il est recommandé de combiner plusieurs appels en une seule requête [API en bloc](https://developer.adobe.com/commerce/webapi/rest/use-rest/bulk-endpoints/){target="_blank"} afin de réduire le nombre de requêtes et d’améliorer les performances. Les clients peuvent demander une augmentation de la [!UICONTROL Maximum Entities Per Bulk Request] en contactant [l’assistance Adobe Commerce](https://experienceleague.adobe.com/en/support?support-tab=home#support). Adobe examinera votre cas d’utilisation et déterminera si l’augmentation de la taille de votre requête en bloc est appropriée. |
